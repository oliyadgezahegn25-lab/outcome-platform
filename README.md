# Outcome Platform

AI that takes an intention and turns it into a real-world outcome.

## Product principle

**USER → STATES WHAT THEY WANT → AI FIGURES OUT HOW → REAL-WORLD OUTCOME**

This is not a marketplace-first product and not a chatbot. The website lets people choose an outcome, describe what they want, and receive an actionable plan.

## First product

- Visual outcome categories
- Guided outcome setup
- AI-ready structured intention model
- Plan and task model
- Outcome dashboard
- Budget and timeline foundations
- "Something Else" for outcomes outside predefined categories

## Initial outcome categories

- Wedding
- Travel
- Study Abroad
- Find a Job
- Move Home
- Buy a Car
- Start a Business
- Plan an Event
- Learn Something
- Organize Healthcare
- Move / Ship Something
- Something Else
